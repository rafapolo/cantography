# Design

How Cantography looks, moves and sounds, one file each. Every value lives in
`index.html`; these files name the constants to search for.

- [look.md](look.md): principles, palette, legal-form colours, type
- [motion.md](motion.md): lamps, timeline, camera, interface, the tour's camera
- [sound.md](sound.md): the tour's music, the map's sound, the moments of a visit
- [tour.md](tour.md): the tour scene by scene, its keys and link options
